# RW Electrical Consulting — Website

Static landing page for RW Electrical Consulting, hosted on Cloudflare Pages.

## Stack

Plain HTML, CSS and vanilla JS — no build step, no framework, no dependencies.

## Structure

```
index.html
assets/
  css/styles.css
  js/main.js
  images/
```

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static file server.

## Deployment (Cloudflare Pages)

- Framework preset: None
- Build command: (none)
- Build output directory: `/`

Connect this repo in the Cloudflare Pages dashboard and it will deploy on every push to the
main branch.
